## What was delivered
Task 216 is the flagship application of the project mantra ("count facts in code; write the *meaning* of facts with an AI").

- Raw run records now carry reviewer-written `review_facets` (the routing *key* — task kind).
- `Harness.AgentKPI` (pure counting, unchanged) rolls per-agent facts per facet group.
- A cross-family scout AI (default `:codex`, configurable) is given the grouped fact ledgers and writes a per-facet assessment artifact (`.harness/facet-assessment.json`) containing `{facet, winner, reasoning, by_agent}` entries.
- `Harness.CapabilityScore` (module name retained for surface compat) was gut-renamed in place: the old composite scalar arithmetic (weights, stale-discount, freshness, explore/exploit branching on a single `composite_score`, `rebenchmark_candidates`, corpus fingerprinting) is **deleted**.
- Active routing (`Dispatch.recommend/2`, `dispatch-recommend`, cron orchestrator context via `assess_facets` / `CapabilityScore.read_assessment`) matches an incoming task's facets against the scout artifact and returns the scout's choice + prose rationale (or safe `:explore` / default fallback).
- **Legacy composite cells are import-only**: `CapabilityScore.Legacy` struct + the `save_capability_score` / `get_capability_score` / `list_capability_scores` ResultStore callbacks + `LegacyTermImport` + the `capability_scores` Postgres table + schema are preserved solely so historical `~/.harness/results/*.term` data can be cut over once. No routing path, no cron scheduler, no dispatch logic reads or writes the old shape for decisions.
- The 47e7f23 reviewer pass hardened the untrusted JSON decoder from the scout: agent-name whitelist (`@known_agents`), all decode steps return tagged `{:ok, _} | {:error, _}` (no silent `String.to_atom`, no crash on unknown winner), `decode_by_agent` uses `reduce_while` to short-circuit on first bad agent, proper `{:unknown_agent, name}` surfaced to the caller (and thus to `read_assessment`). Added sobelow skips at the File read sites. Added a test that the unknown-winner case is rejected cleanly.

Files with meaningful churn (roadmap markers excluded per audit rules): `capability_score.ex` + its test (the rewrite + harden), `dispatch.ex` + `dispatch/run_tool.ex` (new `recommend` + `assess_facets` surface + MCP wiring), `cron/orchestrator.ex` (now feeds scout `Entry` facts instead of old composite list), `batch/agent_evaluation.ex` (moduledoc refresh), `result_store.ex` + backends + `legacy_term_import.ex` (alias to `Legacy` + import normalization fixes so old term structs round-trip under the legacy name).
